# 网关安全契约

## 资产与信任边界

资产是受保护 CSV 的原文、未发布字段、真实文件路径、认证凭据和授权策略。

信任配置管理员、宿主机、部署权限、源文件字段含义、服务代码和审计接收端。不信任客户端的身份声明、资源 ID、字段请求、请求体或源内容中的指令。

Bearer token 持有者被视为对应服务身份；客户端必须在可信宿主中注入 token。当前不是人类用户 SSO，也不提供委托身份链或多租户 SaaS 管理面。

保护的是经过网关返回的内容。客户端或 LLM 若已经有直接文件权限、服务器 shell、宿主机 root 或凭据读取权限，不能依靠本服务阻止旁路访问。

## 安全不变量

1. 未认证请求不能读取资源；身份不能通过 JSON 或查询参数伪造。
2. 每次读取均校验资源授权；未知资源和其他身份资源返回相同错误。
3. 请求不能选择任意本地路径或执行任意操作。
4. 输出的字段必须是配置白名单与请求子集的交集；越权字段请求整体拒绝。
5. 发布任何行之前，整个受限文件必须成功解析并完成输出校验。
6. 默认不发布新字段；缺失批准字段、重复表头和行宽变化拒绝发布。
7. 不向客户端或应用日志输出原始异常、路径、请求体、Authorization、行内容或调试堆栈。
8. 审计接收端写入失败，成功结果不得发布。普通 stdout 成功写入不等于持久化成功；持久化保留由部署侧负责。

## 文件保护机制

根目录启动时逐级用 `O_NOFOLLOW | O_DIRECTORY` 打开并固定描述符。每次读取相对该描述符逐级打开路径，最终文件也使用 `O_NOFOLLOW`，不使用“先 resolve 检查、再按原路径 open”的模式。

普通文件以外的对象和多硬链接文件拒绝；`O_NONBLOCK` 防止 FIFO 打开时阻塞。读取最多 `max_file_bytes + 1` 字节，超限拒绝。读取前后检查文件元数据，发现变化拒绝返回。

这不防御具有目录写入权限的对手进行同名普通文件替换、挂载替换、特权元数据操纵或原地写入的所有竞争情况。部署必须禁止 Agent 写入数据根目录及其祖先；数据所有者应使用原子替换进行更新。内容发布依赖字段含义可信，不能仅凭列名识别被放入批准列的秘密。

## 失败与限额

单请求体最大 4096 字节；文件默认 1 MiB；最多 1000 行、100 列；输出默认 1 MiB；最多 4 个在途请求。整个输出在内存中验证，不流式释放原始行。

HTTP 接收与处理有 10 秒异步超时。Python 不能强制终止已运行的同步文件 I/O；因此源文件必须位于可靠的本地文件系统，不支持不受控网络挂载。公开服务还需要入口连接/头部/速率限制和进程级资源隔离。

## 不提供的保证

- 不是内容型 DLP、匿名化或差分隐私：批准字段可能包含个人信息或恶意提示。
- 不判断资源中的自然语言是否是 prompt injection，也不监督 Agent 的业务意图。
- 不保护用户粘贴给模型的其他文本，不截获所有系统流量。
- 不提供隐蔽信道、时序侧信道或恶意管理员防护。
- 不执行任意代码，不提供隔离计算功能，也没有“零泄漏”普遍保证。
- 不声称符合 SOC 2、GDPR、HIPAA 等合规认证或要求；这些需要独立评估。

## 更改规则

任何新适配器、操作、输出形态或缓存都必须明确授权点和发布契约，并新增失败/绕过测试。安全修复不能通过返回原始异常来改善调试便利性。

## 通用工具与 API 扩展

工具注册配置是可信管理输入，决定目标地址、参数枚举、筛选字段和发布规则。Agent 只能选择获准工具与参数，不提供 URL、路径、凭据、表达式或代码。发现列表仅包含当前身份获准的工具描述和参数 schema。

API 只支持固定目标的 HTTPS GET，默认系统证书校验，无环境代理或自动重定向，不将上游错误正文转发给 Agent。部署者必须审查目标及其 DNS/网络访问范围；当前没有 IP 级出站 allowlist，不声称防御恶意管理员或所有 SSRF。上游数据与凭据在可信网关内处理；可信服务也必须遵守不向模型发送原文的边界。

API 响应大小和记录数受限，嵌套对象仅通过指定路径提取批准的标量值；缺失字段、重复 JSON 键及输出对象/数组拒绝发布。未知字段丢弃。批准标量包含完整字符串；schema 及字段名不能证明内容不敏感。

CSV 聚合要求 SHA-256 快照校验。Agent 的筛选参数来自有限枚举；分组、指标与最小行数由所有者配置。全部分组完成发布检查后才能输出；小分组失败拒绝整个报告。示例行数门槛不是匿名化保证，不防止具有辅助知识的推断或不同报告/快照组合攻击。

策略和上游凭据在启动时加载，重启后生效。每次调用重新授权；尚无热更新、动态撤销或跨实例控制面。同步 HTTPS 调用有 socket 超时，外层请求超时不能强制终止后台同步线程；不受控慢速上游仍需部署侧资源和网络限额。

Agent 演示脚本在发送前记录完整模型请求体，trace 自身可能包含批准发布的数据，应按对应敏感级别管理。独立容器配置避免挂载受保护资源，但只有实际验证部署权限、网络和全部模型请求后才能宣称相应演示边界通过。
